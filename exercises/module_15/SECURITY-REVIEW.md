# Revue de sécurité de la configuration Claude Code de pachaplan

Relue sur `module-15-end`, le <date>, par <vous>, avec Claude Code <version>.

Une trouvaille par bloc `###`, sous la section du composant. Les six champs sont
obligatoires :

- Fichier : le fichier en cause, chemin depuis la racine du dépôt (ou `~/...` pour un
  réglage personnel).
- Permet : ce que la configuration laisse faire, en une phrase.
- Jambe : `données privées`, `contenu non fiable`, `sortie`, `exécution`, une ou
  plusieurs, séparées par des virgules.
- Tenu par : `mécanique` (une règle, le bac à sable, le code), `consigne` (le
  `CLAUDE.md`, une description) ou `rien`.
- Décision : `avant de partager`, `accepté` ou `plus tard`.
- Changement : ce que vous changez, ou pourquoi vous ne changez rien.
